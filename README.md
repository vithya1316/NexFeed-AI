 NexFeed AI

An Intelligent System for Surplus Food Quality Assessment and Redistribution

 Overview

NexFeed AI is a web-based platform developed to reduce food wastage by connecting food donors, NGOs, and volunteers. The system uses Artificial Intelligence to analyze food images and assist NGOs in determining whether food is suitable for redistribution. The platform also supports donation tracking, volunteer coordination, and delivery verification to ensure transparency throughout the process.

 Features

* AI-based food quality assessment using image analysis
* Secure login and registration for donors, NGOs, volunteers, and administrators
* Food donation management and tracking
* NGO verification and approval system
* Volunteer assignment and delivery management
* Delivery verification and status updates
* Admin dashboard for monitoring users and donations

 Modules

Authentication Module

 Provides user registration and login functionality with role-based access control.

Donor Module

 Allows donors to upload food details and food images for redistribution.

AI Food Quality Assessment Module

 Analyzes uploaded food images and predicts whether the food is safe for redistribution.

NGO Module

 Enables NGOs to review donation requests, verify food quality, and accept or reject donations.

Volunteer Module

 Handles food pickup and delivery between donors and NGOs.

Admin Module

 Manages users, approvals, donations, and overall system activities.

 Installation

1. Install XAMPP on your system.
2. Place the project folder inside the htdocs directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Create a database in phpMyAdmin.
5. Import the provided SQL file.
6. Configure the database connection settings if required.
7. Open a browser and run:

http://localhost/NexFeedAI
